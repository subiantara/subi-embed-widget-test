Activities widget

The list only shows when Embeddable widgets → Activities list is switched on for the storefront in staging Platform.Admin.

1. Default snippet

Expect: up to 4 activities in the storefront currency, under the title and description set in Admin (none while those fields are empty). Cards link to the activity detail page on the storefront.

2. Overrides from the page

Expect: up to 8 Sydney activities in GBP, the title and description below, and a carousel with arrows in the header. Card links carry ?currency=USD.

3. Fallbacks

Expect: IDR is not sold, so prices fall back to the storefront currency. data-limit="99" caps at 12. The empty data-title and data-description hide the heading.

4. Empty state

Expect: the agreed "no activities" message, not an error and not a blank box.
